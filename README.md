# MApp (Monitor App)

MApp превращает Android‑телефон в устройство для подключения к серверу и отображения второго монитора.

## Связанный проект
Этот клиент связан с серверным приложением **MAppDesktop для Windows**: `xyfren/MAppDesktop`.

## Основные возможности
- **2 типа подключения:** беспроводное и проводное через USB  
  > Рекомендуется использовать **проводное** подключение для лучшей стабильности и задержек.
- **2 типа кодеков:** `ffmpeg` и `jpeg`
- **3 типа разрешений:** `HD`, `Full HD`, **разрешение телефона**
- **3 типа частоты:** `30`, `60`, **частота обновления телефона**

## Платформа
- **Android**

## Сборка
Проект собирается через **qmake**.
